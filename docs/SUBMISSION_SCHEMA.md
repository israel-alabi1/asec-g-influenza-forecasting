# Provisional forecast schema

The supplied challenge brief requires a forecast CSV but does not publish the portal's exact column names or hidden-test layout. This is an internal adapter, not an official submission schema.

Columns: `season, week_start, epi_week_of_season, location, location_type, outcome, q05, q10, q25, q50, q75, q90, q95`.

Locations: `NATIONAL`, `North`, `South`, and all 36 states + FCT.

Outcomes: `cases`, `hospitalizations`, `deaths`.

Replace this schema only after receiving the official portal instructions.
