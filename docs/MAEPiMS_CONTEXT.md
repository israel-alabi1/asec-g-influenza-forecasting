# MAEPiMS Challenge Context

ASEC-G was developed for the MAEPiMS Challenge 2026 — Nigeria Influenza Forecasting Challenge.

The supplied challenge data are simulated national surveillance data covering three seasons, with national and state-level influenza outcomes and contextual metadata.

The competition requires use of the supplied simulated dataset. The public repository therefore does not redistribute the challenge dataset.

This document records competition context separately from the research identity of ASEC-G so that the method can later be maintained independently of the competition.

The exact organizer portal CSV schema and hidden-test information set were not available in the supplied challenge brief used for the provisional package. The submission adapter must therefore remain explicitly provisional until those instructions are available.
